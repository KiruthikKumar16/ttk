01 Onboarding: Receiving & Validating Single-Use OTP Invite Codes

To protect institutional security, ThoorigAI accounts cannot be self-registered without authorization. An administrator generates an encrypted, single-use OTP invite code specifically authorized for the Staff role.

Step Control / Action How to Use / Details System Outcome API / Route
1 Receive Code Admin generates code via /settings/users → Staff Access Receive code formatted as STAFF-XXXX-YYYY via official institutional channel Email / SMS
2 Inspect Prefix Check that the code prefix is STAFF- Guarantees account receives faculty permissions upon redemption Client Verify
3 Open Registration Link Navigate to https://portal.thoorigai.com/signup?code=STAFF-XXXX-YYYY System checks code against /api/auth/verify-invite?code=STAFF-XXXX-YYYY GET /api/auth/verify-invite
4 Validation Check System confirms code is active, not expired, and not used Registration form initializes with token locked into form context 200 OK
5 Single-Use Redemption Complete form and submit registration Code is permanently consumed upon successful account creation POST /api/auth/signup
💡 Single-Use Enforcement
Every invite code is cryptographically consumed the instant your registration succeeds. The code cannot be used by any other person or for a second registration.

29 Faculty Classroom Emergency Playbook & Quick-Fix Matrix

Classroom Emergency Immediate Action System Recovery Step
Projector Fails to Display QR Projector HDMI cable or input mismatch. Click "Copy Link" button in Classroom QR modal → share direct link via classroom chat channel.
Campus WiFi Outage Mid-Session Local router disconnected or ISP disruption. Keep attendance marking tab open. Marks remain in client memory → click Save Attendance once connection restores.
Student Absent Without Prior Notice Unexcused learner absence in morning roll-call. Mark student as "Absent" → check Watchlist at 05:00 PM → click phone icon to trigger counselor contact link.
Google Sheet Response Sync Error Spreadsheet permissions set to private or URL invalid. Verify spreadsheet is shared with institutional domain or enter scores directly via inline grading inputs.
Accidental Wrong Status Marked Instructor accidentally marked student Absent instead of Present. Click correct status button ("Present") → click "Save Attendance" → verify updated timestamp in Audit Log tab.
