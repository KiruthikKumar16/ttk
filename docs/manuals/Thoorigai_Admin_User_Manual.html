27 Operational Troubleshooting & FAQ Matrix

Symptom / Error Probable Root Cause Resolution Procedure
Invite Code Invalid / Expired Token lifespan (TTL) elapsed or code previously redeemed. Generate a fresh invite code via /settings/users with 7-day validity.
HTTP 403 Forbidden Redirect Logged-in account role lacks permissions for the target module. Check role in /settings/users. Sensitive billing/audit modules require admin role.
Invoice Generation Blocked Missing student tuition fee or invalid registration data. Ensure agreed course fee is greater than zero and learner is enrolled in active course.
Attendance Save Toast Fails Network disconnect or session expiry during roll-call. Click Save Attendance again. If failure persists, verify network and refresh tab.
Certificate Verification Fails Certificate revoked or invalid verification code entered. Check certificate status in /certificates ledger. If revoked, date is recorded.
