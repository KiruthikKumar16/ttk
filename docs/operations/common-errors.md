# Common errors

| Symptom                                                        | Likely cause                                                                                                             | Response                                                                                                                                                                                 |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `503 Server authentication is not configured` or readiness 503 | Missing/invalid server-only Supabase key, DB unreachable, expected migration absent, or private materials bucket missing | Check environment variable presence without printing values; inspect Supabase connectivity, migration version, and bucket configuration. Redeploy after correcting environment settings. |
| `401 Authentication is required`                               | Expired/missing Supabase session or failed refresh                                                                       | Sign in again; check Auth logs and cookie/domain settings. Do not bypass role checks.                                                                                                    |
| `403` or empty mutation result                                 | Role/MFA check or RLS policy rejected the operation                                                                      | Check the user's profile role and AAL2 status, then inspect sanitized Postgres/PostgREST logs using request ID. Fix policy or assignment deliberately.                                   |
| Storage signed URL returns 403                                 | Expired URL, wrong object path, private bucket mismatch, or Storage policy/configuration issue                           | Request a fresh signed URL; confirm course membership/role and private bucket policy. Never make the bucket public as a workaround.                                                      |
| Invoice/download returns 404                                   | Invoice number not found, wrong environment, or record outside requested page                                            | Search by exact invoice reference in the correct project and inspect the request ID. Do not retry using service-role credentials in the browser.                                         |
| Payments fail with 409 or 503                                  | Duplicate idempotency key, balance conflict, transaction failure, or database unavailable                                | Check the stable error envelope and associated request ID. Retry only with the same idempotency key after confirming the first result.                                                   |
| `/api/health` succeeds but `/api/ready` fails                  | Liveness process is active while DB/migration/storage is unavailable or misconfigured                                    | Inspect Supabase DB and Storage health, migration version, and server environment settings.                                                                                              |
| Public verification returns `Invalid`                          | Unknown, revoked, or malformed code; verification backend error is intentionally not exposed                             | Check the public document record and audit history internally. Do not disclose student data through verification diagnostics.                                                            |
| `429` from verification                                        | Per-IP verification rate limit was reached                                                                               | Check the structured `verification_rate_limited` event and proxy/IP configuration. Allow the window to expire; investigate bursts before adjusting limits.                               |
| Sentry error has no readable source frame                      | Release SHA mismatch or source maps not uploaded for that build                                                          | Compare Sentry release to Git SHA and confirm the protected build environment had source-map upload configured.                                                                          |
