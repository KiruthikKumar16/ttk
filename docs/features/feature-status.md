# Feature flows and remaining work

Feature flow documentation: attendance, assessments, certificates, course materials, invoices, reports, settings, students, trainer assignments, and users and roles.

| Feature             | Reachable actions                                                                                                     | Remaining acceptance work                                                                                                               |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Attendance          | Sidebar → Attendance; choose course/date, mark status, mark all present, inspect course/student summaries and history | Local DB/RLS verification, 360px manual check, production load test                                                                     |
| Assessments         | Create assessment, add/edit/delete result, bulk score entry, review distribution chart, export CSV                    | Assessment-definition lifecycle E2E and staging role checks                                                                             |
| Course materials    | Courses → materials; upload with progress, signed URL download, confirm deletion                                      | Storage policy, E2E and staging verification                                                                                            |
| Trainer assignments | Settings → Trainer assignments; admin assigns/unassigns and confirms changes                                          | Local DB/RLS and staging audit verification                                                                                             |
| Settings            | GST settings; trainer assignments; read-only brand values; admin users and roles                                      | Admin MFA flow on staging; decide final legal entity/brand content                                                                      |
| Students            | List, create, student detail, payments and document navigation                                                        | Edit/soft-delete, duplicate-phone warning, CSV dry-run/import/export are not implemented; add authenticated E2E and staging role checks |
| Invoices            | Search/date/student filters, invoice view and PDF download                                                            | Credit-note/void flow is not implemented; GST/business-owner review and staging E2E remain open                                         |
| Certificates        | Fee-gated issue, print, live public verification                                                                      | Revoke/reissue with reason and batch issue are not implemented; staging DB/RLS, E2E and Chromium print comparison remain open           |
| Reports             | Server-computed date filters and streamed CSV export; consistent number formatting                                    | KPI sign-off and staging E2E                                                                                                            |
| Accessibility       | Keyboard focus, labelled forms, confirmation focus trap, live toasts, semantic tables, axe suite                      | Lighthouse ≥95 on deployed pages; manual WCAG contrast and assistive-technology review                                                  |
| Performance         | Keyset history lists, small payloads, local fonts, image optimization, private invoice-PDF cache                      | k6 at target data volume, p95/LCP measurement, and query-plan evidence                                                                  |

See each feature flow document for user actions and error states. The automated local test run is not a substitute for staging verification, production Lighthouse results, or a legal/business review. This table is status evidence, not a claim that the release gate is clear.
