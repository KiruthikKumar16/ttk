# Invoice flows

1. Open **Invoices** to search and page through payment invoices by invoice number, student name, phone, or register ID. Use the payment-date filter for a specific day.
2. Open an invoice row to view the invoice and use **Download PDF** to download a copy.
3. GST settings supply the seller values used in the print view.

Credit notes and voiding with an immutable reference to the original invoice are not implemented. Receipt resend is also unavailable; there is no email-provider flag configured.
