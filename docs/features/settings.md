# Settings flows

- **GST:** `/settings/gst` displays configured invoice GST details. Users with the relevant permission can save changes.
- **Users and roles:** `/settings/users` is admin-only and requires MFA. Role changes are audited; see [users-and-roles.md](users-and-roles.md).
- **Trainer assignments:** `/settings/trainers` is admin-only and assigns or unassigns trainers from courses.
- **Brand information:** `/settings/brand` shows centralized ThoorigAI display, legal, contact, web, and invoice-prefix settings as read-only values.
